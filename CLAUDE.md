## Next.js 16 — read the docs first

This repo runs **Next.js 16.4.3**, which has breaking API, convention, and file-structure changes from older versions. Before writing any Next.js code, read the relevant guide in `node_modules/next/dist/docs/` (resolved from the repo root) and heed deprecation notices. See `AGENTS.md` — that block is auto-regenerated by `next dev`, so commit it with your work rather than deleting it.

## Stack & structure

- TypeScript (strict), React 19, Tailwind CSS v4, npm (`package-lock.json`).
- App Router lives at the repo root in `app/` — there is **no `src/` directory**.
- Import alias: `@/*` → `./*` (root-relative).

## Commands

- `npm run dev` — dev server (Turbopack)
- `npm run build` / `npm run start` — production build / serve
- `npm run lint` — ESLint (`eslint-config-next`, core-web-vitals + typescript)
- No test framework is configured yet.

## Gotchas

- `next.config.ts` enables non-default flags: `cacheComponents`, `partialPrefetching`, and a Turbopack rule routing `*.css` through `@tailwindcss/turbopack`. Keep these in mind when debugging caching, prefetch, or CSS behavior.
